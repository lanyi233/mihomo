# 省电与稳定性复核（2026-10-20）

复核起点：`ac01df89`。从全仓生产代码中的定时器、后台循环、重试与关闭路径入手，重点检查流量统计、DNS、provider 健康检查、Smart 调度、资源更新、NTP、网络切换、TUN、eBPF 和连接维护。此记录是代码审查与回归验证，不是实机功耗测量。

## 修复的问题

| 路径 | 问题 | 修复后的行为 |
| --- | --- | --- |
| 流量统计 | 完全空闲仍每秒唤醒 | 首次有效流量启动采样；输出零速率后停止定时器；并发流量可重新唤醒 |
| AnyTLS 会话池 | 未使用节点也每隔 30 秒执行维护 | 仅在空闲会话数超过保留数量时运行清理定时器 |
| AnyTLS 生命周期 | 取消期间仍可能执行维护；慢速拨号可能在 Close 清空会话表之后注册连接 | 定时等待可取消；关闭与会话注册通过同一把锁衔接；拒绝并关闭迟到的连接 |
| eBPF 共享流表 | 每个流事件都可能触发扫描；分批扫描通过自唤醒连续执行 | 未完成扫描每秒继续一批；压力检查间隔 15 秒；事件合并不延后检查；TCP 释放仍使用独立期限 |
| DHCP DNS | 刷新替换 clients 时与诊断、连接重置发生数据竞争；临时错误可能被缓存一小时 | 加锁获取不可变快照；刷新期间保留期限；失败后允许在接口检查间隔后重试 |
| 网络切换 | 丢失默认接口时也触发全部 provider 测速 | 断网通知取消旧任务、清缓存并重置连接；恢复默认接口后测速 |
| FakeTCP | 清理协程只处理一次；初始化失败可能泄漏 raw socket 或后台协程；设置 TTL 失败会 panic | 持续清理并在关闭时退出；失败路径释放已创建资源；单连接选项错误关闭该连接 |

## 复核依据

- Provider、资源更新、Smart 调度与 NTP 使用后台暂停状态；检查其取消、恢复、退避与并发任务合并路径。
- TUN 和 eBPF 网络监控使用事件通知；eBPF 保留低频漂移检查与故障退避，UDP 维护保留分批预算。
- DNS 连接池的空闲过期由实际池内容驱动；控制器流式响应的定时器随请求结束而停止。
- OpenVPN、SMUX、Sudoku 和 Hysteria 的协议保活、端口跳跃属于已建立连接的维护；本次主要消除无任务维护与无网络探测。

## 验证

- Linux：`CGO_ENABLED=0 SKIP_INTEROP_TEST=1 go test -tags with_gvisor,with_ebpf ./...`。
- 竞态检测覆盖 DNS、流量统计、AnyTLS、FakeTCP、eBPF 监听器，以及 provider、Smart、power、netchange、resource、health、TUN 和控制器。
- 新增确定性虚拟时间测试，检查空闲后恢复采样、取消后跳过回调、AnyTLS 最小会话保留、重复清理、扫描限频和独立 TCP 释放期限；另检查迟到拨号与断网事件取消测速。
- eBPF root 集成测试覆盖 `common/ebpf` 与 `listener/sing_ebpf`，使用私有 mount/bpffs 和测试网络环境。
- Windows 测试与构建；Linux/arm64、Android/arm64、Darwin/arm64 交叉构建；相关包 `go vet`。

环境为 Go 1.27.0、WSL Linux 6.18.33.2。`SKIP_INTEROP_TEST=1` 跳过需要额外互操作环境的用例。Android 构建通过不代表 Android 实机续航或挂起恢复已测量；本次没有新增实机电量、温度或吞吐数据。
